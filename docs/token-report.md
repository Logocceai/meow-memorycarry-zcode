# Token 节省与档位成本实测

meow-memorycarry-zcode 的隔离实验实测结果。实验日期 2026-09-16,模型 `opencode/deepseek-v4.1-flash[1m]`,10 个实验全部一次通过(10/10)。

## 摘要

| 场景 | 结果 | 对照 |
|---|---|---|
| 短上下文(lab-lite) | 输出 token 减少 **72.9%** | 6,330 → 1,718;墙钟 52.6s → 32.1s |
| 长上下文(lab-full) | 输出 token 减少 **74.8%** | 10,609 → 2,676;墙钟 87.2s → 39.1s |
| 速度档 s1 vs s3 | 墙钟缩短 **31.1%** | 短素材 151.5s → 104.4s |

```text
短上下文  ██████████████████████░░░░░░░░  72.9%    6,330 → 1,718 output tokens
长上下文  ███████████████████████░░░░░░░  74.8%   10,609 → 2,676 output tokens
```

对照关系:同一道"恢复上次任务上下文"的问题,无记忆时必须重新探索项目文件,有记忆时只读 `.zcode/memory/` 里的索引、分层文件与快照。

## 实验问题

- **节省**:有记忆时,新窗口恢复上次任务上下文,比无记忆重新探索省多少 token?
- **速度档成本**:s1 / s2 / s3 压缩一次各花多少时间与额度?
- **上下文规模**:短(lab-lite)与长(lab-full)两种场景的差异。

## 方法与环境

- **隔离环境**:两套实验仓库(lab-lite 6 文件 / lab-full 15 文件),各自独立 git 与记忆库基线,不与任何真实项目数据接触。
- **协议驱动**:全部会话由固定提示词发起;E5/E6 素材相同,唯一变量为速度档,每轮实验前重置基线。
- **执行方式**:`zcode.cjs` 无头(CLI)串行执行,单实验超时 600s,失败自动重试一次。
- **实验序列**:E1/E2 短上下文(无记忆 / 有记忆)、E3/E4 长上下文(无记忆 / 有记忆)、E5-s1/s2/s3 短素材三档、E6-s1/s2/s3 长素材三档。
- **数据来源**:离线必读量由字符折算(中文字符 × 0.7 + 其他字符 × 0.25);实测 token 与耗时从本机会话日志按时间窗提取,仅聚合数字、不读会话内容。

## 一、恢复上下文成本(离线必读量)

| 路径 | lab-lite(短) | lab-full(长) |
|---|---|---|
| 无记忆:探索项目全部文件 | 6 文件 / 4,107 字符 / ≈1,172 tokens | 15 文件 / 15,002 字符 / ≈4,199 tokens |
| 有记忆:索引 + 分层 + 快照 | 7 文件(2 快照)/ ≈743 tokens | 10 文件(5 快照)/ ≈1,205 tokens |
| 记忆库全量 | 7 文件 / ≈921 tokens | 10 文件 / ≈1,857 tokens |
| 离线估算节省 | 429 tokens(36.6%) | 2,994 tokens(71.3%) |

```text
lab-lite(短)
  无记忆探索    ████████                          1,172
  有记忆 recall █████                             743

lab-full(长)
  无记忆探索    ██████████████████████████████  4,199
  有记忆 recall █████████                       1,205
```

口径:无记忆 = 重新探索项目全部文件;有记忆 = INDEX + 项目分层 + 快照清单 + 最新快照。这是**保守口径**,不含工具调用与试错开销(真实差距 ≥ 本图)。

## 口径与局限

- **实测 vs 估算**:实测 = 会话日志的真实 usage 与耗时;估算 = 必读内容的字符折算。两者分区展示,不以估算冒充实测。
- **保守性**:离线节省口径不计工具调用轮次、system prompt 重复与试错开销,因此真实会话节省 ≥ 报告中数值。
- **方差**:每个实验单次执行,长上下文探索路径存在模型行为随机性;如需更稳的结论可重复执行取均值。
- **token 系数**:中文 0.7/字、其余 0.25/字符(经验系数);更换精确分词器会导致绝对值变化,但对比关系不变。

## 数据与复现

- 原始数据:实验目录的 `measurements/`(`baseline.json` 离线估算、`session-usage.json` 实测聚合、`raw/` 逐实验输出留档)。
- 实验协议与提示词:同目录 `PROTOCOL.md` 与 `prompts/`(10 段固定提示词)。
- 执行器:`run-experiments.mjs`(串行、超时、重试、断点续跑),可重复执行同一批实验。
