# 记忆载入(meow-recall)

从记忆库把上个窗口的进度"带回来":读索引、按需读详情、输出摘要、确认继续点后动工。

## 执行流程

1. **定位记忆库**:当前仓库根 `.zcode/memory/INDEX.md`。
   - 不存在 → 告知用户该仓库还没有记忆库,询问是初始化(由 `/handoff` 首次执行时创建)还是直接开始新任务;不擅自创建。

2. **读索引**:读 INDEX.md 的活跃任务、下一步、最近快照三个小节。

3. **按需读详情**(按当前任务相关性挑,不是全部通读):
   - `project.md`:项目状态
   - 最近 1-3 份 `status: active` 的快照(`handoffs/` 下按文件名倒序取)
   - `decisions.md` / `lessons.md` / `facts.md`:与任务相关的条目(单文件 ≤120 行,可整读)

4. **输出载入摘要**,固定三段、全摘要 ≤30 行:
   - **上次进度**:最近快照的 Summary 与 Done 要点
   - **相关决策与教训**:只列与本次任务直接相关的条目
   - **下一步建议**:INDEX"下一步"与最近快照 Next 的合并

   摘要末尾向用户确认"从哪里继续",得到答复再动工。

5. **继续任务**:按确认的起点执行;本窗口产生的新信息由 `/handoff` 在收尾时带走。

## 边界

- 只读 `.zcode/memory/`,不修改记忆文件(写入是 `/handoff` 的职责)。
- 不凭空编造:记忆库为空或缺少某类信息时明确说"记忆库没有记录",禁止补写臆测内容。
- 载入摘要超过 30 行说明读得太多,回退到只读 INDEX 与最近 1 份快照。
